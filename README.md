## 🎮 Game Glitch Investigator: The Impossible Guesser

# How to Play:
   # Select the current difficulty of the number guessing game.
   You are given a set number of guesses to make per mode. You have 8 guesses for easy, 5 for medium, and 3 for hard.
   # Range
   The range of the score decreases from a total pool (100) with decriments decreasing with certain game modes. Selecting a Game Mode will override your current attempts.
   # Hints
   You can toggle guessing hints on or off depending on the mode, gesturing you to go higher or lower depending on the input of your guess.
